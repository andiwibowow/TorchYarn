# TorchYarn

TorchYarn enables real-time data processing through distributed, autonomous deployment of modular, scalable systems.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/TorchYarn.git`
2. `cd TorchYarn`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TorchYarn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
